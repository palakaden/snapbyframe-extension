Privacy Policy — Snap by Frame

Last updated: September 26, 2026
In short: Snap by Frame does not collect, store, transmit, or sell any user data. Everything the extension does happens locally, inside your own browser.

What we collect

Nothing. Snap by Frame does not collect personal information, browsing history, analytics, telemetry, or any other data about you or your activity. There are no servers involved — the extension never makes a network request of any kind.

How the extension works

When you trigger Snap by Frame (via Alt+Shift+S or the toolbar icon), it captures an image of the current tab and lets you crop, annotate, and export it — all of this happens in your browser's memory only:

  • The captured image is never uploaded anywhere.
  • Copy places the finished image on your device's local clipboard.
  • Save writes the image to your own computer using Chrome's standard downloads feature, at a location you control.
  • If you close the editor without saving or copying, the image is discarded and gone — nothing is retained.

Permissions this extension uses

  • activeTab — lets the extension read and capture the current tab's content only when you explicitly trigger it.
  • scripting — injects the selection and annotation tool into the active tab after you trigger a capture.
  • notifications — shown only if a capture or save fails, so you know something went wrong.
  • downloads — used only when you click Save, to write the PNG file to your chosen download location.

Third parties

None. No data is shared with, sold to, or processed by any third party, advertiser, or analytics provider.

Children's privacy

This extension does not knowingly collect data from anyone, including children, because it does not collect data at all.

Changes to this policy

If this ever changes — for example, if a future version adds an optional feature that involves data leaving your device — this page will be updated first, the change will be disclosed prominently in the extension's Chrome Web Store listing, and (where applicable) you'll be asked for consent before it takes effect.
